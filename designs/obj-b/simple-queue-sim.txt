Idea here is to make a single queue that has a single server

Input: 
- A queue config file as specified by the slides, example can be found in examples/obj-b
- A wl.csv generated by our workload generator this will contain the list of jobs and their tasks

Computation:
- Our program will read in the queue config file and create a queue as specified by the config given.
- This created queue will start working through the jobs as specified by the given wl.csv file
- The python example queue as given by our prof is the exact logic our simple queue should follow.
- It should work through all given jobs as specified and generate the correct output.

Output:
- qmet.csv should be outputted that shows the stats requested the format is specified by our slides and an example is given in examples/obj-b 
- jobs.log should be outputted which is a step by step log of every action that happens regarding our queue example is given in examples/obj-b
- Our queue should write to the given sink if there is one specifying the jobs that were completed.
